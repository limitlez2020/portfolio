# Personal Portfolio

A portfolio website created to showcase my skills and experiences, designed with a modern bento-grid layout. This project highlights my professional journey and allows visitors to explore my work in a visually appealing and intuitive format.

## Project Overview

This personal portfolio website was developed using React.js and styled with Tailwind CSS. The site is organized in a bento-grid format, providing a clean and structured layout that effectively presents my skills, projects, and professional experiences. The use of Heroicons adds to the visual appeal and usability of the site.

## Features

- **Bento-Grid Layout**: A modern and visually engaging grid format to display content.
- **Responsive Design**: Ensures the portfolio looks great on all devices, from desktops to mobile phones.
- **Interactive Elements**: Smooth and intuitive navigation powered by React.js.
- **Iconography**: Enhanced with Heroicons for a sleek and modern look.

## Technologies Used

- **React.js**: For building the interactive and dynamic user interface.
- **Tailwind CSS**: For styling and creating a responsive, mobile-friendly design.
- **Heroicons**: For adding elegant and consistent icons throughout the site.

## Usage

Link:  https://limitlez2020.github.io/portfolio/

Explore my portfolio to view detailed information about my skills, projects, and professional journey. The bento-grid layout provides a unique and organized way to navigate through the content.
